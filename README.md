# Kylapse

Synapse PACS del Hospital San Juan de Dios desde el celular: búsqueda por RUT, informes y visor con presets de ventana, series y 1 o 2 cuadros.

Instalación: abre https://kylapse.github.io/kylapse/ en el celular y sigue los pasos.

- `sm.js`: programa que carga el marcador (versión minificada de `sm.src.js`).
- `loader.js`: código del marcador.
- No guarda ni envía datos de pacientes: corre dentro de la sesión de Synapse de cada usuario.
